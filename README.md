## Faculty Glyphic Kannada

Faculty Glyphic Kannada is a Kannada companion to Faculty Glyphic, the typeface designed by Dylan Young at Koto London in 2024. It brings Faculty Glyphic’s carved, glyphic character to the Kannada script, so Kannada and Latin text can be set together in one voice.

The Kannada follows the rules of the original Latin: the same x-height, the same stroke weight and contrast, and the same diamond tittle. The Latin is included unchanged.

Faculty Glyphic was created by Koto Studio as a modern tribute to Berthold Wolpe’s Albertus, drawing on carved typography and the work of Edward Johnston. The Kannada letterforms are adapted from Noto Sans Kannada.
